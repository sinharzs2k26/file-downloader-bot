# Telegram Download Manager Bot

A powerful Telegram bot that downloads files from direct URLs and sends them back to you - just like a cloud-based download manager!

## ✨ Features

### 📥 **Download Capabilities**
- Download any file from direct HTTP/HTTPS links
- Support for all common file formats:
  - **Videos**: MP4, AVI, MKV, MOV, WMV, FLV, WEBM
  - **Documents**: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT
  - **Archives**: ZIP, RAR, 7Z, TAR, GZ
  - **Images**: JPG, JPEG, PNG, GIF, BMP, WEBP
  - **Audio**: MP3, WAV, OGG, M4A, FLAC
  - **Applications**: APK, EXE, DMG, ISO

### ⚡ **Performance Features**
- Real time download & upload progress bar
- Smart file type detection
- Automatic filename extraction from URLs
- File size validation before download
- 2GB max file size

### 🤖 **User Experience**
- Simple commands: `/start`, `/help`, `/status`
- Direct URL input (just paste and send!)
